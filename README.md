# Abdul Mubeen - Professional Portfolio

This repository contains the personal portfolio website of Abdul Mubeen, a Software Engineering graduate and Web Manager.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Build for production:
   `npm run build`
